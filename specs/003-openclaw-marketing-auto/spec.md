# Feature Specification: OpenClaw 기반 Weibo 마케팅 자동화 관리 시스템

**Feature Branch**: `003-openclaw-marketing-auto`
**Created**: 2026-02-22
**Status**: Draft
**Input**: User description: "일본 부동산을 중국인 대상으로 판매하는 Weibo 계정의 마케팅 자동화. 운영자가 부동산 사진과 내용을 작성하면 OpenClaw이 Weibo 발행 및 관리를 자동화하고, 중국 내 유사 성공 계정을 벤치마킹하여 전략을 최적화한다."

## Clarifications

### Session 2026-02-22

- Q: Weibo 계정의 콘텐츠 주제/니치는? → A: 일본 부동산을 중국인 대상으로 판매하는 마케팅 계정. 운영자가 직접 부동산 사진과 내용을 작성하고, 시스템은 발행 자동화 및 관리를 담당. 중국 내 유사 성공 계정을 벤치마킹하여 전략 수립.
- Q: 현재 포스팅 빈도와 목표 빈도는? → A: 하루 1-2건 적극적 운영 목표.
- Q: OpenClaw의 역할 범위는? → A: OpenClaw이 Telegram 허브 역할. 스케줄링, 벤치마킹, 리포팅 모두 OpenClaw을 경유하며, 운영자는 하나의 채팅 인터페이스에서 모든 것을 관리한다.
- Q: 벤치마킹 경쟁 계정을 어떻게 확보하나? → A: 운영자가 알고 있는 계정을 직접 등록하고, OpenClaw이 Weibo에서 유사 계정을 자동 검색하여 추가 추천한다.
- Q: 콘텐츠 생성 범위의 제약은? → A: 콘텐츠는 두 종류로 구분한다. (1) 매물 포스트: 실제 부동산 사진, 가격, 위치, 설명 등은 반드시 운영자가 수동으로 작성. OpenClaw은 매물 정보를 절대 생성/수정하지 않음 (허위 매물/할루시네이션 방지). (2) 전문가 콘텐츠: 운영자가 매물을 올리지 않는 날에 OpenClaw이 일본 부동산 시장 동향, 투자 팁, 지역 소개 등 전문가 계정다운 글을 자동 작성하여 발행. 계정이 일본 부동산 전문가로 인식되도록 유지한다.
- Q: 주요 취급 지역은? → A: 주로 오사카 근교 부동산. 전문가 콘텐츠와 해시태그 전략도 오사카/간사이 지역 중심으로 운영한다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - OpenClaw 통한 콘텐츠 발행 관리 (Priority: P1)

운영자가 일본 부동산 사진과 일본어 소개 텍스트를 Telegram으로 전달하면, 기존 포스팅 파이프라인(일→중 번역, 환율 변환, 해시태그 생성, Weibo 업로드)이 실행된다. OpenClaw은 이 전체 과정을 감독하고, 발행 대기열을 관리하며, 하루 1-2건의 최적 시간대에 발행을 스케줄링한다.

**Why this priority**: 기존 시스템(002)이 이미 단건 포스팅을 처리하지만, 여러 건의 콘텐츠를 미리 준비해두고 최적 시간에 자동 발행하는 기능이 없다. 하루 1-2건 꾸준한 운영의 핵심 기능이다.

**Independent Test**: 3-4건의 콘텐츠를 한꺼번에 전송하고, 설정된 시간대에 맞춰 순차 발행되는지 확인하여 독립 테스트 가능.

**Acceptance Scenarios**:

1. **Given** 운영자가 여러 건의 부동산 콘텐츠(사진+텍스트)를 한꺼번에 전송한 상태, **When** 다음 최적 발행 시간이 도래, **Then** 대기열에서 1건을 꺼내 기존 파이프라인(번역→해시태그→업로드)을 실행하고 결과를 보고한다
2. **Given** 발행 대기열에 콘텐츠가 있는 상태, **When** 운영자가 "대기열 확인"을 요청, **Then** 대기 중인 콘텐츠 목록과 예정 발행 시간을 보여준다
3. **Given** Weibo 쿠키가 만료된 상태, **When** 발행 시간이 도래, **Then** 발행을 일시 중단하고 운영자에게 쿠키 갱신을 알리며 대기열을 보존한다

---

### User Story 2 - 경쟁 계정 벤치마킹 (Priority: P1)

OpenClaw이 중국 Weibo에서 일본 부동산을 판매하는 성공적인 경쟁 계정들을 주기적으로 모니터링한다. 인기 포스트의 패턴(포맷, 해시태그, 발행 시간, 이미지 스타일)을 분석하여 운영자에게 인사이트 리포트를 Telegram으로 전달한다.

**Why this priority**: 운영자가 "잘 나가는 계정을 벤치마킹"하길 원하며, 이는 콘텐츠 전략의 방향을 결정하는 핵심 정보이다. 경쟁자가 무엇을 하는지 모르면 효과적인 마케팅이 불가능하다.

**Independent Test**: 경쟁 계정 3-5개를 등록하고, 분석 리포트가 생성되는지 확인하여 독립 테스트 가능.

**Acceptance Scenarios**:

1. **Given** 운영자가 경쟁 계정 목록(Weibo UID 또는 닉네임)을 등록한 상태, **When** 주간 벤치마킹 시간이 도래, **Then** 각 계정의 최근 인기 포스트, 발행 빈도, 사용 해시태그, 인게이지먼트 수준을 분석한 리포트를 Telegram으로 전달한다
2. **Given** 경쟁 계정이 높은 인게이지먼트의 새 포스트를 발행한 상태, **When** OpenClaw이 이를 감지, **Then** 해당 포스트의 핵심 요소(제목, 해시태그, 이미지 수, 텍스트 길이)를 분석하여 운영자에게 알린다
3. **Given** 한 달 이상 벤치마킹 데이터가 축적된 상태, **When** 운영자가 "경쟁 분석 요약"을 요청, **Then** 경쟁 계정 대비 우리 계정의 성과 비교 및 개선 제안을 제공한다

---

### User Story 3 - 전문가 콘텐츠 자동 생성 (Priority: P1)

운영자가 매물을 올리지 않는 날에, OpenClaw이 일본 부동산 전문가 계정답게 관련 콘텐츠를 자동으로 작성하여 발행한다. 예: 일본 부동산 시장 동향, 투자 수익률 분석, 인기 지역 소개, 세금/비자 정보, 매매 절차 안내 등. 매물 정보가 아닌 **정보성 콘텐츠**만 자동 생성한다.

**Why this priority**: 하루 1-2건 꾸준한 발행이 목표인데, 매일 매물이 있는 것은 아니다. 빈 날에 전문가 콘텐츠로 채워야 계정이 활발하고 신뢰감 있게 유지된다.

**Independent Test**: 매물을 올리지 않고 하루를 기다렸을 때, OpenClaw이 자동으로 적절한 전문가 콘텐츠를 생성하여 발행하는지 확인.

**Acceptance Scenarios**:

1. **Given** 당일 운영자가 매물 포스트를 전송하지 않은 상태, **When** 다음 예정 발행 시간이 도래하고 대기열이 비어있음, **Then** OpenClaw이 일본 부동산 관련 정보성 콘텐츠(시장 동향, 투자 팁 등)를 자동 생성하여 발행한다
2. **Given** 운영자가 이미 매물 1건을 올린 상태, **When** 두 번째 발행 슬롯이 비어있음, **Then** 전문가 콘텐츠로 자동 채워서 하루 2건 발행 목표를 유지한다
3. **Given** 전문가 콘텐츠가 자동 생성된 상태, **When** 해당 콘텐츠에 실제 매물 가격이나 특정 물건 정보가 포함되어 있는지 검증, **Then** 특정 매물 정보는 포함되지 않으며 일반적인 시장 정보/투자 지식만 포함된다

---

### User Story 4 - 발행 시간 최적화 (Priority: P2)


OpenClaw이 중국 Weibo 사용자의 활동 패턴과 벤치마킹 데이터를 기반으로 일본 부동산 콘텐츠의 최적 발행 시간대를 자동으로 결정한다. 하루 1-2건의 포스트를 가장 노출이 높은 시간에 배치한다.

**Why this priority**: 같은 콘텐츠라도 발행 시간에 따라 조회수가 수배 차이날 수 있다. 특히 일본 부동산에 관심 있는 중국인의 Weibo 사용 패턴에 맞춰야 한다.

**Independent Test**: 다양한 시간대에 발행한 후 성과를 비교하여, 추천 시간대의 성과가 더 높은지 확인.

**Acceptance Scenarios**:

1. **Given** 벤치마킹 데이터와 자체 발행 기록이 존재하는 상태, **When** 새 콘텐츠가 대기열에 추가, **Then** 최적 시간대(중국 시간 기준)를 자동으로 배정한다
2. **Given** 2주 이상의 발행 성과 데이터가 축적된 상태, **When** 운영자가 "최적 시간 분석"을 요청, **Then** 시간대별 평균 조회수/인게이지먼트 분석 결과를 제공한다

---

### User Story 5 - 성과 추적 및 리포팅 (Priority: P2)

OpenClaw이 발행된 각 부동산 포스트의 성과(조회수, 좋아요, 댓글, 공유)를 자동 수집하고, 주간 리포트를 Telegram으로 전달한다. 어떤 유형의 매물(지역, 가격대, 구조)이 가장 반응이 좋은지 패턴을 분석한다.

**Why this priority**: 어떤 매물이 인기인지 알아야 콘텐츠 전략을 개선할 수 있지만, 발행과 벤치마킹이 우선이므로 P2.

**Independent Test**: 발행된 포스트 10건 이상의 성과가 수집되고 주간 리포트가 생성되는지 확인.

**Acceptance Scenarios**:

1. **Given** 포스트 발행 후 24시간이 경과한 상태, **When** 성과 수집 시간이 도래, **Then** 각 포스트의 조회수, 좋아요, 댓글, 공유 수를 수집하여 저장한다
2. **Given** 일주일 이상 성과 데이터가 축적된 상태, **When** 주간 리포트 시간(매주 월요일 오전), **Then** 주간 발행 요약, 포스트별 성과 순위, 매물 유형별 반응 분석을 Telegram으로 전달한다

---

### User Story 6 - 해시태그 및 콘텐츠 포맷 최적화 (Priority: P3)

벤치마킹과 성과 데이터를 기반으로, OpenClaw이 해시태그 전략과 콘텐츠 포맷(텍스트 길이, 이미지 수, 이모지 사용 등)의 개선안을 자동으로 제안한다. 기존 해시태그 생성기의 태그 목록을 데이터 기반으로 업데이트한다.

**Why this priority**: 최적화는 기본 운영과 데이터 축적이 선행되어야 의미가 있으므로 P3.

**Independent Test**: 제안된 해시태그 변경 사항이 실제 성과 향상으로 이어지는지 A/B 비교.

**Acceptance Scenarios**:

1. **Given** 한 달 이상의 벤치마킹 및 자체 성과 데이터가 축적된 상태, **When** 월간 최적화 분석 시간이 도래, **Then** 경쟁 계정에서 효과적인 해시태그, 우리 계정에서 성과 좋은/나쁜 해시태그를 비교 분석하여 변경 제안을 전달한다

---

### Edge Cases

- OpenClaw 서비스가 다운되거나 응답하지 않을 때, 발행 대기열의 콘텐츠는 어떻게 처리되는가? → 기존 Telegram 봇이 대기열을 유지하며, OpenClaw 복구 시 순차 처리
- Weibo 쿠키가 만료되었을 때 → 즉시 Telegram 알림 발송, 대기열 보존, OpenClaw이 자동 갱신 시도 (기존 cookie_manager의 refresh 기능 활용)
- 경쟁 계정이 비공개로 전환하거나 삭제된 경우 → 해당 계정을 모니터링 목록에서 비활성화하고 운영자에게 알림
- 하루 2건 이상의 콘텐츠가 대기열에 쌓였을 때 → 최적 시간 슬롯에 맞춰 순서대로 배치, 초과분은 다음 날로 이월
- Weibo가 포스팅 빈도 제한(rate limit)을 적용할 때 → 발행 간격을 자동으로 늘리고 운영자에게 알림

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 기존 Weibo 포스팅 파이프라인(002)을 그대로 활용하며, 기존 Telegram 봇에 스케줄링, 벤치마킹, 리포팅 기능을 직접 확장한다. OpenClaw은 Skills를 통해 이 기능들을 호출하는 보조 인터페이스로 동작하며, OpenClaw 없이도 기존 봇 명령어로 모든 기능을 사용할 수 있어야 한다
- **FR-002**: 시스템은 여러 건의 콘텐츠를 대기열에 저장하고, 설정된 시간에 순차 발행할 수 있어야 한다
- **FR-003**: 시스템은 하루 1-2건의 포스팅 빈도로 최적 시간대(중국 시간 기준)에 자동 발행할 수 있어야 한다
- **FR-004**: 시스템은 운영자가 지정한 경쟁 Weibo 계정(일본 부동산 판매 계정)의 포스트를 주기적으로 수집·분석할 수 있어야 한다
- **FR-005**: 시스템은 경쟁 계정의 인기 포스트 패턴(해시태그, 발행 시간, 포맷, 인게이지먼트)을 분석한 벤치마킹 리포트를 생성할 수 있어야 한다
- **FR-006**: 시스템은 발행된 포스트의 성과 지표(조회수, 좋아요, 댓글, 공유)를 자동 수집할 수 있어야 한다
- **FR-007**: 시스템은 주간 성과 리포트를 자동 생성하여 Telegram으로 전달할 수 있어야 한다
- **FR-008**: 시스템은 성과 및 벤치마킹 데이터를 기반으로 해시태그, 발행 시간, 콘텐츠 포맷 개선안을 제안할 수 있어야 한다
- **FR-009**: 시스템은 Weibo 쿠키 만료 시 자동 갱신을 시도하고, 실패 시 운영자에게 즉시 알려야 한다
- **FR-010**: 시스템은 기존 미리보기(preview)/자동(auto) 발행 모드를 유지하면서 대기열 기반 스케줄링을 추가해야 한다
- **FR-011**: 시스템은 매물 콘텐츠(사진, 가격, 위치, 설명 등 실제 부동산 정보)를 절대 자동 생성하거나 수정해서는 안 된다. 모든 매물 정보는 반드시 운영자가 직접 작성한 원본을 사용해야 한다 (허위 매물/할루시네이션 방지)
- **FR-012**: 시스템은 운영자가 매물을 올리지 않는 날에 일본 부동산 전문가 콘텐츠(시장 동향, 투자 팁, 지역 소개, 세금/비자 정보 등)를 자동 생성하여 발행할 수 있어야 한다
- **FR-013**: 자동 생성된 전문가 콘텐츠에는 특정 매물의 가격, 주소, 사진 등 실제 물건 정보가 포함되어서는 안 되며, 일반적인 시장 정보와 투자 지식만 포함해야 한다

### Key Entities

- **발행 대기열(Publish Queue)**: 운영자가 전송한 콘텐츠의 발행 순서. 콘텐츠 참조, 예정 발행 시각, 상태(대기/처리중/완료/실패)를 포함
- **경쟁 계정(Competitor Account)**: 벤치마킹 대상 Weibo 계정. UID, 닉네임, 모니터링 시작일, 활성화 여부를 포함
- **벤치마킹 리포트(Benchmark Report)**: 경쟁 계정 분석 결과. 인기 포스트, 해시태그 분석, 발행 패턴, 인게이지먼트 비교를 포함
- **성과 데이터(Performance Data)**: 발행된 포스트별 시계열 성과 지표. 수집 시점, 조회수, 좋아요, 댓글, 공유를 포함
- **최적화 제안(Optimization Suggestion)**: 데이터 기반 개선 권고. 해시태그 변경, 발행 시간 조정, 포맷 개선 등을 포함

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 하루 1-2건의 Weibo 포스트가 최적 시간대에 자동 발행된다
- **SC-002**: 운영자가 콘텐츠 전송 후 발행까지의 수동 개입이 0회이다 (자동 모드 기준)
- **SC-003**: 경쟁 계정 3개 이상의 벤치마킹 리포트가 매주 자동 생성된다
- **SC-004**: 발행된 포스트의 성과 데이터가 24시간 이내에 자동 수집된다
- **SC-005**: 주간 성과 리포트가 매주 정해진 시간에 Telegram에 자동 전달된다
- **SC-006**: 3개월 운영 후 평균 포스트 인게이지먼트(좋아요+댓글+공유)가 벤치마킹 도입 전 대비 30% 이상 향상된다
- **SC-007**: 발행 스케줄의 95% 이상이 예정된 시간(±10분)에 정상 실행된다

## Assumptions

- 기존 Weibo 쿠키 기반 포스팅 시스템(002-weibo-cookie-posting)이 정상 작동 중이다 (번역, 해시태그, 이미지 처리, 포스팅 파이프라인 포함)
- OpenClaw은 Raspberry Pi(Linux ARM)에서 실행 가능하다 (이미 쿠키 갱신에 localhost:18789로 사용 중)
- 운영자가 일본 부동산 콘텐츠(사진+일본어 텍스트)를 직접 작성하여 Telegram으로 전달한다
- 경쟁 계정의 공개 포스트는 Weibo 웹 크롤링으로 수집 가능하다
- 콘텐츠 번역은 기존 Claude API 파이프라인(일본어→중국어)을 그대로 사용한다
- 목표 발행 빈도는 하루 1-2건이다
- 주요 취급 지역은 오사카 근교이며, 전문가 콘텐츠와 해시태그 전략도 오사카/간사이 지역 중심이다
