# Contract: Telegram Bot Commands

**Date**: 2026-02-22

## Bot Commands

| Command | Description | Response |
|---------|-------------|----------|
| `/start` | Bot 시작/안내 | 사용법 안내 메시지 |
| `/preview` | 미리보기 모드 전환 (기본) | "미리보기 모드가 활성화되었습니다." |
| `/auto` | 즉시 포스팅 모드 전환 | "자동 포스팅 모드가 활성화되었습니다. 다음 매물부터 즉시 포스팅됩니다." |
| `/status` | 현재 모드 확인 | "현재 모드: 미리보기/자동" |

## Input Message Format

### 사진 + 텍스트 (일반 매물 입력)

**Input**: Telegram MediaGroup (사진 1~9장) + 캡션 또는 텍스트 메시지
- 사진은 `media_group_id`로 그룹핑
- 텍스트는 캡션 또는 별도 텍스트 메시지 (자유 형식)
- 지원 언어: 일본어, 중국어, 한국어

**Response (미리보기 모드)**:
```
📋 매물 미리보기

🏠 物件名称: ○○マンション
📍 所在地: 東京都港区...
💰 价格: ¥35,000,000 (约 ¥170万人民币)
...

#日本房产 #东京 #海外投资

[포스팅] [수정 요청]
```

**Response (자동 모드)**:
```
✅ Weibo 포스팅 완료!
🔗 https://weibo.com/...
```

### 사진 초과 시
```
⚠️ 사진이 9장을 초과합니다. 처음 9장만 사용됩니다.
```

## Callback Buttons

| callback_data | Action | Response |
|--------------|--------|----------|
| `approve_{post_id}` | Weibo 포스팅 실행 | "⏳ 포스팅 중..." → "✅ 포스팅 완료! 🔗 {url}" |
| `reject_{post_id}` | 수정 요청 | "수정할 내용을 입력해주세요." |

## Error Messages

| Situation | Message |
|-----------|---------|
| 번역 실패 | "❌ 번역 중 오류가 발생했습니다. 잠시 후 다시 시도해주세요." |
| 포스팅 실패 (재시도 중) | "⏳ 포스팅 재시도 중... ({n}/3)" |
| 포스팅 최종 실패 | "❌ Weibo 포스팅에 실패했습니다. 에러: {error_message}" |
| 환율 API 장애 | "⚠️ 환율 정보를 가져올 수 없어 {date} 기준 환율을 사용합니다." |
